# Captain Usage page consolidation

Activity now has one Captain Usage tab: usage charts first, the selected-bucket mission drill-down when open, and the current Account Limits table at the bottom. The shared global breadcrumb and captain View Usage hint use the new label. The previous standalone Account Limits tab and its unused panel were removed.

The page keeps the stable `source=usage-overview` URL. Old `source=usage-limits`, `tab=limits` and `source=tokens&tab=limits` bookmarks replace their URL with the merged page and `section=account-limits`, preserving provider/account/host filters and scrolling to the account section after charts finish loading. New captain provider-history links use that canonical destination directly. One identity filter form controls both charts and table. The page refresh also reloads the table; its existing pagination, sorting, column controls, independent refresh and automatic refresh remain available. Chart errors do not remove the table. The account-wide usage note remains visible because the account table is present even with Tokens only selected.

The full Dashboard suite passes 1,859 tests across 237 suites (`npm run test:run -- --maxWorkers=4`). Existing integration tests cover the single tab row, account table placement after charts, shared filtering/refresh, chart drill-down, table retry and legacy link normalization. Dashboard production build and strict Mobile/shared Dashboard lint pass. All 11 TUI parity tests pass; the regenerated TUI and Mobile manifests pass their gates with no planned entries. The new labels and refresh hint are translated in all eight non-English catalogs; the usage-specific localization gate passes.

An owned disposable Admiral served the actual Dashboard. Five views (Captain Usage, its Tokens only selection, old account-limit URL, old nested limits URL and standalone Token Usage) were checked in light/dark at 1440, 768 and 390 pixels: 30 cases. Checks require one shared breadcrumb, the Captain Usage label, no separate Account Limits tab, the account table below the charts, preserved legacy URL filters and no document horizontal overflow. Tables retain contained horizontal scrolling on phones. Screenshots were visually inspected for hierarchy, spacing, contrast and wrapping.
