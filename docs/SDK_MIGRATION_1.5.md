# Armada.Client 1.5.0 migration

Armada.Client 1.5.0 groups the REST calls into one sub-client per area. Every 1.4 flat method on `ArmadaClient` is
removed; call the sub-client property instead. Arguments, return types, and behavior are unchanged.

```csharp
// 1.4
Mission? mission = await client.GetMissionAsync(id);
EnumerationResult<Fleet>? fleets = await client.ListFleetsAsync();

// 1.5
Mission? mission = await client.Missions.GetAsync(id);
EnumerationResult<Fleet>? fleets = await client.Fleets.ListAsync();
```

`ArmadaClient` keeps `Options`, `BaseUrl`, `SetToken`, `SendRawAsync`, `Dispose`, and the `Unauthorized` and
`RequestCompleted` events. `ArmadaClient` is now sealed. Each sub-client method that mirrors a dashboard
`api/client.ts` function carries `[DashboardExport("name")]` with that function's name.
